(2026-05-23). The build is green, `go vet` is clean, and the test suite passes,

proto parser, the gRPC `go.mod`, the compiler, and `--version`.

Highlights:

- **Type fidelity** — OpenAPI 3.x and Swagger 2.0 `$ref` schemas are now
  resolved for both `requestBody` and parameters (with cycle guards); boolean
  params generate native `BoolVar` flags; array params are entered as
  comma-separated values and expanded into repeated query values or typed JSON
  body arrays; `required` (including each schema's `required` list) drives
  generated-CLI validation.
- **gRPC** — the proto parser is now a depth-aware, brace-balanced tokenizer
  that correctly handles nested messages, maps, enums, oneofs, field options,
  and block/line comments; generated gRPC `go.mod` no longer declares phantom
  `grpc`/`grpcurl` module requires (verified: `go mod tidy` downloads nothing).
- **Storage & UX** — raw specs are cached under `~/.bawarchi/specs` (0600) so
  `update` survives a moved/offline source; generated source is written
  owner-only (0700 dir / 0600 files); multi-server specs expose environment
  selection via `<NAME>__SERVER=<index>`; generated CLIs return exit 4 on 4xx
  and 5 on 5xx; the compiler stays quiet on success and only surfaces toolchain
  output on failure; `bawarchi --version` is wired up.

## Known Limitations / Future Candidates

These are deliberate, bounded scoping choices from this cycle — not regressions.
They are candidates for a future cycle if demand warrants:

- **Nested object body fields** are surfaced as a single raw-JSON string flag
  rather than being recursively flattened into per-leaf flags.
  - Sources: internal/parser/openapi.go (bodyParamsResolve)
- **Top-level array request bodies** are skipped with a warning (no named
  fields to map to flags).
  - Sources: internal/parser/openapi.go (bodyParamsResolve)
- **gRPC repeated and map fields** are passed as comma-separated / raw-JSON
  strings rather than typed slices/maps (the REST path has typed array support).
  - Sources: internal/parser/proto.go (protoFieldToParam, parseMapField)
- **Multi-server selection** is index-based via `<NAME>__SERVER`; there is no
  per-invocation `--server` flag or named-environment lookup yet.
  - Sources: internal/generator/rest.go (init), internal/parser/openapi.go
